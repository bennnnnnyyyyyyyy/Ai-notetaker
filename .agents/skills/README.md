# Project-local skills

These skills are deliberately small and project-specific. They supplement Codex's general skills; they do not replace the repository instructions in `AGENTS.md`.

- `project-workflow` — keep code, plans, worklogs, and reviews separated.
- `fastapi-local` — work safely within this local FastAPI/SQLite layout.
- `post-patch-validation` — run proportional checks and report what was not tested.
