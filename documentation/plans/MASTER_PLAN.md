# Master Plan

The project advances in small, testable milestones. Keep unfinished work explicit.

## Milestone 1 — Capture proof of concept

Verify that this PC can open an authorized Google Meet session in a visible browser and save both sides of the call to a real local audio file with explicit user consent.

Deliverables: environment check, audio-device check, FFmpeg test recording, visible-browser join test, and a documented result.

## Milestone 2 — Reliable local pipeline

Make recording lifecycle handling reliable, then connect transcription and persistence using a short fixture recording before using a real meeting.

## Milestone 3 — Evidence-based analysis

Run the existing eight-stage analysis pipeline through Ollama, validate the report schema, and show report status and errors in the dashboard.

## Milestone 4 — Workflow hardening

Add retries, cleanup, explicit consent/status states, test fixtures, structured logs, and safe handling for partial recordings.

## Milestone 5 — Pilot readiness

Run authorized pilot meetings, review report quality, document privacy/retention rules, and decide whether deployment or authentication is warranted.

No milestone is complete until its checklist is updated and the work is recorded in the worklog.
